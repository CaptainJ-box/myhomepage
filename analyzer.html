자동 데이터 분석기

CSV나 엑셀 파일을 올리면 열을 분석하고, 요약 문장과 어울리는 차트를 추천해 드려요.

1단계

파일 올리기

2단계

열 자동 분석

열마다 숫자 · 날짜 · 항목 · 텍스트 중 어떤 종류인지 자동으로 판별했어요.

3단계

자동 요약

    확인이 필요한 값

    평균에서 표준편차의 3배 이상 벗어난 값입니다. 입력 실수인지 확인해 보세요.

      4단계

      차트 추천

      카드를 누르면 크게 보고, 축과 집계 방식을 바꿀 수 있어요.

      추천할 차트가 없습니다. 숫자·날짜·항목 열이 있는 데이터를 올려 보세요.

      5단계

      AI에게 물어볼 요약 복사

      원본 데이터는 빼고 열 이름, 종류, 통계, 상위값, 자동 요약만 담았어요.

      입력한 내용은 이 브라우저 안에서만 처리되며 어디에도 저장·전송되지 않습니다.
